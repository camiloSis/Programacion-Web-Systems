Sumillado: Variable Aleatoria Discreta y sus Medidas Descriptivas

Esperanza, Varianza, Desviación Estándar, Asimetría y Curtosis.

1

Esperanza Matemática y Varianza

Esperanza / Media

Fórmula
$$E(X) = \mu = \sum x_i \cdot f(x_i)$$
Sumilla: Es el promedio ponderado o valor medio esperado a largo plazo tras repetir el experimento muchas veces.

Varianza

Fórmula original
$$Var(X) = \sum (x_i - \mu)^2 \cdot f(x_i)$$
Fórmula práctica
$$Var(X) = E(X^2) - \mu^2$$
Sumilla: Mide la dispersión promedio de los datos al cuadrado respecto a la media.

Desviación Estándar

Fórmula
$$\sigma = \sqrt{Var(X)}$$
Sumilla: Mide la dispersión o variación típica de los valores en las mismas unidades originales que la variable $X$.
2

Asimetría ($S_k$)

Coeficiente de Asimetría

Fórmula
$$S_k = \frac{\mu_3}{\sigma^3} = \frac{E[(X - \mu)^3]}{\sigma^3}$$
Fórmula desarrollada para $\mu_3$
$$\mu_3 = E(X^3) - 3\mu E(X^2) + 2\mu^3$$

Criterios de interpretación

ValorInterpretación
$S_k = 0$ Simétrica Distribución Simétrica.
$S_k > 0$ Positiva Asimetría Positiva (sesgada a la derecha).
$S_k < 0$ Negativa Asimetría Negativa (sesgada a la izquierda).
3

Curtosis ($K_x$)

Coeficiente de Curtosis

Fórmula
$$K_x = \frac{\mu_4}{\sigma^4} = \frac{E[(X - \mu)^4]}{\sigma^4}$$
Sumilla: Se compara con la distribución normal, cuyo valor de referencia es $K_x = 3$.

Criterios de interpretación

ValorInterpretación
$K_x = 3$ Mesocúrtica Apuntamiento normal.
$K_x > 3$ Leptocúrtica Muy apuntada / colas pesadas.
$K_x < 3$ Platicúrtica Plana o achatada.
4

Ejemplo Integrador de Referencia

Caso: Llamadas de reclamo

Función de probabilidad $f(x)$
$x_i$ 0 1 2 3
$f(x_i)$ 0.1 0.4 0.3 0.2
Resultados
Media
$\mu = 1.6$
Promedio esperado de llamadas
Desviación estándar
$\sigma = 0.92$
Variación típica
Asimetría
$S_k = +0.094$
Asimétrica positiva
Curtosis
$K_x = 2.10$
Platicúrtica
Ver verificación rápida de la media y la varianza
$$E(X) = 0(0.1) + 1(0.4) + 2(0.3) + 3(0.2) = 1.6$$ $$E(X^2) = 0^2(0.1) + 1^2(0.4) + 2^2(0.3) + 3^2(0.2) = 3.4$$ $$Var(X) = E(X^2) - \mu^2 = 3.4 - 1.6^2 = 0.84 \;\Rightarrow\; \sigma = \sqrt{0.84} \approx 0.92$$
Recuerda: una asimetría cercana a 0 indica una distribución casi simétrica, y una curtosis menor que 3 indica un apuntamiento más plano que el de la distribución normal.
